# Local visual assets

Copy the existing working prototype's static folder into this directory for the exhibition version. Expected paths: static/wro.png, static/next.png, static/culture.png and static/flags/<lowercase ISO code>.png.

Third-party logos and flag images are not included pending confirmation of redistribution rights. The dashboard HTML contains the existing embedded map geometry; its provenance and redistribution terms must be checked before merging. Do not publish participant databases or audio tracks. Supply licensed MP3 files separately on the FAT32 microSD card.
